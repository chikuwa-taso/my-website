Positions

募集職種

営業職

Job Description

印刷物の企画提案・受注管理・顧客折衝。既存顧客へのフォローと新規開拓を担当。デザイン・制作・工場スタッフと連携し、お客様の要望を形にするディレクション業務も含みます。

Requirements

普通自動車免許。印刷・広告・デザイン業界での経験歓迎。未経験者も歓迎します。

Employment Type

正社員

制作・DTP職

Job Description

Adobe IllustratorおよびInDesignを使用した印刷データの整備・デザイン・面付け。お客様入稿データの確認から印刷用PDFの出力まで一連の工程を担当します。

Requirements

Illustrator・InDesignの実務経験。印刷知識（色校正・製版・CMYK管理）があれば尚可。

Employment Type

正社員・契約社員

印刷オペレーター

Job Description

オフセット輪転機・枚葉印刷機の操作および品質管理。色調管理・インキ調整・機械の保守点検。先輩スタッフによるOJTで未経験から学べます。

Requirements

経験不問。印刷機械への興味・ものづくりへの意欲を重視します。

Employment Type

正社員
